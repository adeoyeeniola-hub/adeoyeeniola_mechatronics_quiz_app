# Mechatronics Quiz App

## What it does
This is a Python quiz application that tests users' knowledge of Mechatronics through multiple-choice questions.

Users can answer questions, check their scores and see their grades.

## How to run it
1. Download the Python file.
2. Open it in a Python editor.
3. Run the program.
4. Enter your name and follow the instructions.

## Sample output
The program displays:
- User's name
- Quiz questions and options
- Correct answers when an answer is wrong
- Final score and grade

## My own twist
I added a feature that shows the correct answer when a user selects a wrong option. Users can also choose how many questions they want to answer.

## What I learned
I learned how to use Python functions, lists, loops, conditional statements and user input to build a simple quiz application.
